Описание протокола связи Master–Slave
Протокол обеспечивает обмен данными между ведущим (Master) и ведомым (Slave) устройствами по интерфейсу RS-485. Формат пакетов — текстовый, с контролем целостности через контрольную сумму.

Общие параметры
Интерфейс: RS-485 (реализован через SoftwareSerial на Arduino).

Скорость передачи: 9600 бод.

Формат пакета: текстовый, с разделителями и контрольной суммой.

Адресация: каждое ведомое устройство имеет уникальный адрес (1 байт, в шестнадцатеричном формате, 2 символа).

Контроль целостности: вращающаяся контрольная сумма (алгоритм описан ниже).

Структура пакета
Пакет от Master к Slave (запрос)
Формат: >AACCNN[DATA]\n

Где:

> — стартовый символ (1 байт).

AA — адрес целевого ведомого устройства (2 шестнадцатеричных символа, 1 байт в числовом представлении).

CC — код команды (2 символа).

NN — номер ячейки данных (2 шестнадцатеричных символа, значение от 00 до 0F / 0–15).

[DATA] — опциональные данные (для команд записи), передаются в текстовом виде.

\n — стоповый символ (перевод строки, 1 байт).

Пакет от Slave к Master (ответ)
Формат: <AASS[DATA][CHK]\n

Где:

< — стартовый символ (1 байт).

AA — адрес ведомого устройства (2 шестнадцатеричных символа).

SS — статус выполнения (2 символа):

OK — команда выполнена успешно.

ER — ошибка (неверная контрольная сумма, неверный адрес, неизвестная команда, выход за границы диапазона и т. п.).

[DATA] — данные (для команд чтения) или пустые (для команд записи).

[CHK] — контрольная сумма (2 шестнадцатеричных символа).

\n — стоповый символ.

Алгоритм контрольной суммы
Используется вращающаяся контрольная сумма (rotating checksum):

Начальное значение суммы — 0.

Для каждого байта данных:

Выполняется циклический сдвиг текущего значения суммы влево на 1 бит (старший бит переходит в младший).

К полученному значению прибавляется очередной байт данных.

Результат — 1 байт (выводится в шестнадцатеричном формате).

Пример функции на C++:

cpp
uint8_t calc_rotating_checksum(const uint8_t *data, size_t len) {
  uint8_t sum = 0;
  for (size_t i = 0; i < len; i++) {
    sum = (sum << 1) | (sum >> 7);
    sum += data[i];
  }
  return sum;
}
Команды
Команды чтения (от Master к Slave)
Команда	Описание	Данные в ответе
R1	Считать бит	Значение бита (0 или 1)
RB	Считать 1 байт	Значение байта (в десятичном формате)
RD	Считать 2 байта (слово)	Значение слова (в десятичном формате)
RT	Считать 3 байта	Значение (младшие 3 байта 32-битного числа, в десятичном формате)
RL	Считать 4 байта (длинное значение)	Значение (в десятичном формате)
RX	Считать текст (8 байт)	Строка из 8 символов
GS	Получить статус	Строка статуса (например, OK01)
Команды записи (от Master к Slave)
Команда	Описание	Данные в запросе
WB	Записать 1 байт	Значение в десятичном формате
WD	Записать 2 байта (слово)	Значение в десятичном формате
WT	Записать 3 байта	Значение в десятичном формате (младшие 3 байта)
WL	Записать 4 байта (длинное значение)	Значение в десятичном формате
WX	Записать текст (8 байт)	Строка (дополняется пробелами до 8 символов или обрезается)
Примеры обмена
Пример 1: Чтение байта
Запрос (Master → Slave): >02RB01\n
(Запросить чтение байта №1 у устройства с адресом 0x02).

Ответ (Slave → Master): <02OK123A4\n
(Устройство 0x02, статус OK, значение байта — 123, контрольная сумма — A4).

Пример 2: Запись байта
Запрос (Master → Slave): >02WB01255\n
(Записать значение 255 в байт №1 устройства с адресом 0x02).

Ответ (Slave → Master): <02OKA1\n
(Устройство 0x02, статус OK, контрольная сумма — A1).

Пример 3: Ошибка контрольной суммы
Запрос (Master → Slave): >02RB01XX\n
(Некорректный пакет — контрольная сумма не совпадает).

Ответ (Slave → Master): <02ERB2\n
(Устройство 0x02, статус ER (ошибка), контрольная сумма — B2).

Особенности реализации
Буферизация: пакеты накапливаются до символа \n, затем обрабатываются.

Проверка адреса: если адрес в пакете не совпадает с адресом устройства, пакет игнорируется.

Обработка ошибок: при любой ошибке (неверный адрес, команда, контрольная сумма) возвращается статус ER.

Хранение данных: в ведомом устройстве есть массивы для хранения байтов, слов, длинных значений и строк (по 16 ячеек каждого типа).
