Вот полный код функций расчёта и проверки контрольной суммы для Arduino в рамках описанного протокола:
-----------
cpp
/**
 * Расчёт вращающейся контрольной суммы.
 * Алгоритм: для каждого байта данных выполняется циклический сдвиг текущего значения суммы влево на 1 бит
 * (старший бит переходит в младший), затем к результату прибавляется очередной байт данных.
 *
 * @param data Указатель на массив данных, для которых рассчитывается контрольная сумма.
 * @param len Длина массива данных (в байтах).
 * @return Контрольная сумма (1 байт).
 */
uint8_t calc_rotating_checksum(const uint8_t *data, size_t len) {
  uint8_t sum = 0;
  for (size_t i = 0; i < len; i++) {
    sum = (sum << 1) | (sum >> 7);  // Циклический сдвиг влево на 1 бит: старший бит переходит в младший
    sum += data[i];                 // Прибавление очередного байта данных
  }
  return sum;
}

/**
 * Проверка контрольной суммы входящего пакета.
 * Извлекает контрольную сумму из пакета, рассчитывает контрольную сумму для полезной нагрузки
 * и сравнивает их.
 *
 * @param packet Входящий пакет в виде строки (включая стартовый символ '>' и стоповый '\n').
 * @return true, если контрольная сумма верна, false — в противном случае.
 */
bool validate_checksum(const String& packet) {
  // Проверка минимальной длины пакета и стартового символа
  if (packet.length() < 8 || packet[0] != '>') {
    return false;
  }

  // Выделяем полезную нагрузку (без стартового символа '>' и стопового '\n')
  // -1(>) -1(\n) -2(CHK) — вычитаем длину стартового/стопового символов и контрольной суммы
  int payloadLen = packet.length() - 4;
  String payload = packet.substring(1, 1 + payloadLen);

  // Извлекаем контрольную сумму из пакета (последние 2 символа перед '\n')
  char chkStr[3] = {packet[packet.length() - 3], packet[packet.length() - 2], '\0'};
  uint8_t receivedChksum = (uint8_t)strtol(chkStr, NULL, 16);

  // Рассчитываем контрольную сумму для полученной полезной нагрузки
  uint8_t calculatedChksum = calc_rotating_checksum((const uint8_t*)payload.c_str(), payload.length());

  // Сравниваем полученную и рассчитанную контрольные суммы
  return (receivedChksum == calculatedChksum);
}
Пример использования в обработке пакета
Ниже — фрагмент функции parsePacket, демонстрирующий, как использовать validate_checksum для проверки целостности пакета перед его обработкой:

cpp
void parsePacket(String packet) {
  // Если контрольная сумма не совпадает — отправляем ошибку и завершаем обработку
  if (!validate_checksum(packet)) {
    sendResponse("ER", "");
    return;
  }

  // Извлекаем адрес устройства из пакета
  char addrStr[3] = {packet[1], packet[2], '\0'};
  uint8_t addr = (uint8_t)strtol(addrStr, NULL, 16);
  if (addr != MY_DEVICE_ADDR) {
    // Пакет не для этого устройства — игнорируем
    return;
  }

  // Обрабатываем команду и данные (далее следует логика обработки команд)
  // ...
}

Как это работает: пошаговое объяснение
Расчёт контрольной суммы (calc_rotating_checksum):

Инициализируем sum = 0.

Для каждого байта в данных:

Выполняем циклический сдвиг sum влево на 1 бит: (sum << 1) | (sum >> 7). Это означает, что старший бит переходит в младший разряд.

Прибавляем к sum текущий байт данных.

Возвращаем итоговое значение sum (1 байт).

Проверка контрольной суммы (validate_checksum):

Проверяем, что пакет имеет достаточную длину и начинается со стартового символа >.

Извлекаем полезную нагрузку (часть пакета между > и контрольной суммой).

Из пакета извлекаем переданную контрольную сумму (последние 2 символа перед \n).

Рассчитываем контрольную сумму для извлечённой полезной нагрузки.

Сравниваем рассчитанную и переданную контрольные суммы. Если они совпадают — пакет корректен.

Пример расчёта контрольной суммы
Допустим, полезная нагрузка — строка "02OK" (адрес 02, статус OK).

Преобразуем строку в байты: [0x30, 0x32, 0x4F, 0x4B] (ASCII-коды символов).

Начальное значение sum = 0.

Обработка каждого байта:

Байт 0x30:

Сдвиг: sum = (0 << 1) | (0 >> 7) = 0.

Прибавление: sum = 0 + 0x30 = 0x30.

Байт 0x32:

Сдвиг: sum = (0x30 << 1) | (0x30 >> 7) = 0x60 | 0x00 = 0x60.

Прибавление: sum = 0x60 + 0x32 = 0x92.

Байт 0x4F:

Сдвиг: sum = (0x92 << 1) | (0x92 >> 7) = 0x24 | 0x01 = 0x25 (учитываем перенос бита).

Прибавление: sum = 0x25 + 0x4F = 0x74.

Байт 0x4B:

Сдвиг: sum = (0x74 << 1) | (0x74 >> 7) = 0xE8 | 0x00 = 0xE8.

Прибавление: sum = 0xE8 + 0x4B = 0x133. Учитываем только младший байт: 0x33.

Итоговая контрольная сумма: 0x33 (в шестнадцатеричном формате — "33").
