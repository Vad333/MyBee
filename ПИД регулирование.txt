Добавить ПИД библиотеку для управления
Критическое предупреждение: для обогрева улья любые самодельные терморегуляторы — потенциально опасны. 
Для пчёл критичен узкий диапазон температур (35–40 °C), а перегрев грозит гибелью семьи и пожаром. 
Для реального применения настоятельно рекомендую готовые сертифицированные термостаты. 
Ниже — только учебный пример для понимания принципа.

Какую библиотеку выбрать
Для Arduino есть две популярные реализации ПИД:

PID_v1 (библиотека PID) — классический вариант, проверенный годами.
GyverPID — более лёгкая, удобная, с дополнительными функциями.
Для вашей задачи (обогрев улья) проще и надёжнее взять GyverPID: она проще в настройке и меньше грузит Arduino.

Как установить GyverPID
В Arduino IDE откройте: Скетч → Подключить библиотеку → Управление библиотеками.
В поиске введите GyverPID.
Нажмите «Установить».
Либо скачайте ZIP с GitHub и добавьте через Скетч → Подключить библиотеку → Добавить .ZIP библиотеку.

Полный пример кода с ПИД и твердотельным реле (SSR)
Этот код управляет нагревателем 12 В через SSR, поддерживая целевую температуру. Датчик — DS18B20 (цифровой, точный, герметичный).

//*********************** cpp
#include <OneWire.h>
#include <DallasTemperature.h>
#include <GyverPID.h>

// --- НАСТРОЙКИ ---
const float setpoint = 37.0;      // Целевая температура, °C
const int relayPin = 3;           // Пин для SSR

// ПИД-коэффициенты (подбираются экспериментально)
// Kp — реакция на текущее отклонение
// Ki — убирает остаточную ошибку (накопление)
// Kd — сглаживает резкие скачки
const float Kp = 4.0;
const float Ki = 0.5;
const float Kd = 0.1;

// --- ОБЪЕКТЫ ---
OneWire oneWire(2);               // Пин для DS18B20
DallasTemperature sensors(&oneWire);
GyverPID regulator(Kp, Ki, Kd, 1000); // 1000 — период расчёта в мс

void setup() {
  Serial.begin(9600);
  sensors.begin();
  pinMode(relayPin, OUTPUT);
  digitalWrite(relayPin, LOW);   // Выключено

  regulator.setDirection(REVERSE); // REVERSE: чем выше температура, тем меньше мощность
  regulator.setLimits(0, 100);     // Выход ПИД от 0 до 100 (проценты)
  regulator.setSetpoint(setpoint);
}

void loop() {
  sensors.requestTemperatures();
  float temp = sensors.getTempCByIndex(0);

  if (isnan(temp)) {
    Serial.println("Ошибка датчика температуры!");
    return;
  }

  // Обновляем вход ПИД
  regulator.compute(temp);
  int output = regulator.getOutput(); // 0…100

  // Логика для SSR: это ВКЛ/ВЫКЛ, но с длительностью по ПИД
  // Реализуем простой «временной ШИМ» на базе периода ПИД (1 сек)
  static unsigned long lastTime = 0;
  unsigned long now = millis();
  const unsigned long period = 1000; // 1 секунда

  if (now - lastTime >= period) {
    lastTime = now;
    int onTime = (output * period) / 100; // Сколько мс включать
    digitalWrite(relayPin, HIGH);
    delay(onTime);
    digitalWrite(relayPin, LOW);
    // Оставшееся время до конца периода SSR выключен
  }

  Serial.print("Temp: ");
  Serial.print(temp, 1);
  Serial.print(" C, Output: ");
  Serial.println(output);
}
//***********************

Как это работает
ПИД получает текущую температуру и выдаёт значение 0–100 — это «сколько процентов мощности нужно».
SSR не умеет плавно менять мощность, поэтому мы делаем временной ШИМ: в каждом периоде (1 секунда) SSR включён столько миллисекунд, сколько соответствует проценту от ПИД.
Например, если ПИД выдал 30, то SSR включён 300 мс и выключен 700 мс.
REVERSE в setDirection нужен, потому что при росте температуры мощность должна уменьшаться (для нагревателя).
Как подбирать коэффициенты (Kp, Ki, Kd)
Это самый ответственный этап. Делайте это вне улья, на тестовом стенде.

Начните с Kp = 2…5, Ki = 0, Kd = 0.
Смотрите, как система реагирует: если сильно «качает» температуру (то горячо, то холодно) — уменьшайте Kp.
Если температура медленно ползёт к цели и не доходит — добавьте Ki (начните с 0.1–0.5).
Если есть резкие скачки и выбросы — добавьте небольшое Kd (0.05–0.2).
Цель: плавный выход на 37 °C без колебаний больше ±1 °C.

Важные нюансы именно для улья
Период ПИД 1 с — оптимален для инерционного объекта (дно улья, мат). Более быстрый период даст рывки, более медленный — медленную реакцию.
Аварийный термопредохранитель на 40–45 °C обязателен в силовой цепи независимо от электроники.
Датчик должен быть в зоне расплода, но не касаться рамок, в герметичной капсуле.
Тестовый прогон вне улья: 15–30 минут, контроль запаха, локальных перегревов, стабильности показаний.
Если хотите использовать PID_v1 вместо GyverPID
Логика та же, но синтаксис другой:

//*********************** cpp
#include <PID_v1.h>
double Setpoint = 37.0, Input, Output;
PID myPID(&Input, &Output, &Setpoint, 4.0, 0.5, 0.1, REVERSE);
И в loop():

cpp
Input = temp;
myPID.Compute();
// Output 0–255, нужно масштабировать под ваш период ШИМ
//***********************

Но для новичка GyverPID проще: меньше кода, понятнее параметры.
